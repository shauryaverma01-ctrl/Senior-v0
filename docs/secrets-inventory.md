## Recoverability of values

Supabase masks all secret values after they're set — even the dashboard shows only digests. The values exist only at the original source:

| Secret | Where the value lives now |
|---|---|
| `ZORONAL_WEBHOOK_SECRET` | Zoronal dashboard webhook auth field. Also: **add to 1Password** so it's redundantly stored. |
| `TELEGRAM_BOT_TOKEN` | Your BotFather chat history (`/mybots` → token). Also: **add to 1Password**. |
| `TELEGRAM_MANAGER_CHAT_ID` | Telegram message metadata (recoverable via `getUpdates` API). Also: same value is in `restaurants.telegram_chat_id` for TBDC — query the DB. |

If `1Password vault: Senior` doesn't exist yet, create it and paste the three rotatable secrets there. Cost: 2 minutes. Benefit: never rebuild from scratch.
