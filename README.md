# Senior v0

This is the v0 build for Senior, an AI voice concierge for Indian restaurants. It picks up inbound restaurant phone calls via Zoronal, captures reservations and answers FAQs in English/Hindi, and routes confirmations and complex requests to the manager via a Telegram bot. v0 is an internal test deployment at The Blue Door Cafe (Khan Market, Delhi) built on Supabase Edge Functions over a 5-day window. See `CLAUDE.md` for architecture and hard rules, and `docs/` for the PRD, Maya prompt, and runbook.
